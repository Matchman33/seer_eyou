插件系统

封包拦截

实时拦截游戏收发包，支持查看、修改、丢弃、劫持。精准匹配 cmdId，自定义处理逻辑。

✨

内置插件

内置插件清单由云端配置，首次启动自动安装，设置页可一键下载全部内置插件。
